# Модуль 1: "Хирургия текста"
На этом уровне мы мыслим текстовыми объектами и используем регистры как буферы для сложных операций.

## Основные инструменты
|**Команда**|**Философия / Что делает**|
|---|---|
|**`ciw` / `caw`**|Изменить внутри слова (inner) / Изменить слово с пробелом (around).|
|**`di"` / `da"`**|Удалить всё внутри кавычек / Удалить вместе с кавычками.|
|**`ya{`**|Скопировать (yank) весь блок кода вместе с фигурными скобками.|
|**`"0p`**|Вставить из регистра `0`. Vim сохраняет последний скопированный текст (`y`) в нулевой регистр. Обычный `p` вставляет то, что ты удалил (`d`). `"0p` спасает, когда ты что-то скопировал, потом удалил строку и хочешь вставить скопированное.|
|**`qq` ... `q`**|Записать макрос в регистр `q`. Макросы — это запись последовательности нажатий. Запускается макрос через `@q`.|

##  Training File 1: Манипуляция объектами
Создай файл `mod1.json` и вставь туда этот код:

```json
{
  "users": [
    { "id": 123, "name": "john_doe", "status": "active" },
    { "id": 456, "name": "jane_smith", "status": "active" },
    { "id": 789, "name": "bob_jones", "status": "active" }
  ],
  "settings": {
    "theme": "dark",
    "notifications": "enabled"
  }
}
```

**Задачи и Minimal Keystroke Challenge:**
1. **Задача:** Заменить `john_doe` на `admin_user`.
    - **Действие:** Поставь курсор куда угодно внутри `"john_doe"`.
    - **Challenge:** 14 нажатий -> `ci"` + `admin_user` + `Esc`.
2. **Задача:** Превратить все статусы `"active"` в `"inactive"` (используя магию точки).
    - **Действие:** Курсор на `active` -> `ci"` -> `inactive` -> `Esc`. Спустись на следующую строку (`j`), прыгни к статусу и нажми `.`.
3. **Задача:** Скопировать блок `settings` и вставить его ниже, но не потерять его, если перед вставкой ты случайно удалишь пустую строку.
    - **Действие:** Курсор внутри блока settings -> `ya{`. Удалить строку -> `dd`. Вставить скопированный блок -> `"0p`.
