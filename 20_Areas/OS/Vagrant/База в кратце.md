**Vagrant** - это инструмент для управления виртуальными машинами. В основном работает на базе VirtualBox 

## Основные понятия 

- **[[Vagrantfile]]**
	- Главный файл конфигурации где описано:
		- Какую виртуалку использовать
		- Сколько памяти/CPU использовать
		- Какие порты использовать
		- Скрипт при запуске
- **Box** - это готовые образы виртуальной машины (Ubuntu, CentOs) 
- **Provisioning** - автоматическая настройка виртуалки

### Команды
- Init (Ubuntu)
```bash
vagrant init ubuntu/trusty64
```

- Поднимаем
```bash
vagrant up
```

- Подключаем
```bash
vagrant ssh
```

- Остановить
```
vagrant halt
```

- Destroy
```sh
vagrant destroy
```
